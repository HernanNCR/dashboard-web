# dashboard-web

Aplicación web para controlar contenido multimedia
en OBS Studio mediante una interfaz web.

## Tecnologías

Frontend:
- React
- TypeScript
- Vite

Backend (próximamente):
- Node.js
- Express
- Socket.IO

## Objetivo

Permitir crear sesiones temporales donde un usuario
pueda subir archivos y controlar qué contenido se
muestra en OBS en tiempo real.
